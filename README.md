# The Third Light

> *Seventeen years ago, a vessel followed the wrong light into the reef. You signed the report that blamed its captain. Now the woman who found proof has vanished.*

A six-chapter psychological island mystery built with **Three.js** and **Blender** assets.

## 🌊 Features

- **First-person 3D exploration** of storm-battered Greywake Island
- **Six chapters** of escalating psychological mystery
- **Dynamic weather** — mist rolls across the water, rain lashes the windows
- **Journal & case board** systems to track conflicting evidence
- **Ambient soundtrack** — piano, rain, sea, and wind layered in real-time
- **Plays in the browser** — no install needed (desktop Chrome/Edge recommended)

## 🎮 The Story

You're the investigator who signed the wreck report seventeen years ago. The
official record says the third light was never on. But Iris Hale found proof
that it was — and now she's missing.

Her message led you back to Greywake.

## 🛠️ Built With

- **Three.js** — 3D rendering, procedural island generation
- **Blender** — lodge, archive, radio house, signal tower models
- **Vanilla JS** — game logic, dialogue, journal systems
- **Web Audio API** — dynamic layered ambience
